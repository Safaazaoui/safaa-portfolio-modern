# Safaa Zaoui Portfolio

Modern animated portfolio built with Vite, React, and CSS motion.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy to GitHub Pages

1. Create a GitHub repository named `safaa-portfolio-modern`.
2. Push this folder to GitHub.
3. Run:

```bash
npm run build
npm run deploy
```

If you use a different repository name, update the `homepage` field in `package.json`.
